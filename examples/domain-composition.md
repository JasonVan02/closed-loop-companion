# Marketing companion

**User:** “Use $marketing-creative-director to design the campaign. Use $closed-loop-companion to govern delivery and independent review.”

**Route:** FULL — the user explicitly requests independent review for a formal creative deliverable.

**Responsibilities:** the marketing skill develops strategy and creative directions; the companion checks the brief, promised deliverables, supporting evidence and review coverage. It does not choose marketing strategy in place of the domain skill.

**Outcome:** collect authorized references and actual deliverables, classify findings and repair as needed. READY_FOR_USER_ACCEPTANCE requires the agreed evidence and reviews; the user makes final creative choices. If the named domain skill is absent, report the gap and use an authorized available method.
