# High-fidelity UI

**User:** “Use the installed UI/design skill for visual implementation and $closed-loop-companion for evidence-based review. Do not treat build success as visual acceptance.”

**Route:** FULL — matching a visual reference requires visible evidence.

**Flow:** the design skill handles layout and visual choices; the companion requires the reference, actual current screenshot/render, viewport and matching implementation. Verify the external reviewer can actually see the images.

**Outcome:** missing images or an unavailable image channel leave visual criteria unverified. Build/test success alone cannot reach the agreed visual gate. READY_FOR_USER_ACCEPTANCE still awaits the user's aesthetic acceptance.
