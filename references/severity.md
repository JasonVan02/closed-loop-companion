# Severity

| 级别 | 含义 | Gate |
|---|---|---|
| CRITICAL | 数据损坏、安全缺陷、根本方向错误、严重需求偏离或重大回归 | 必须为 0 |
| MAJOR | 核心 AC 不满足、关键流程不可用、明显架构债务、关键测试缺失、视觉方向错误 | 必须为 0 |
| MINOR | 非核心细节、维护性或非阻塞视觉/文案问题 | 由 Contract minor_findings_block 决定 |
| NOTE | 可选建议 | 不阻塞，不新增为本轮需求 |

严重性必须与具体影响对应，不能为了得到 PASS 下调级别。被撤回/解决的旧 finding 保存在旧轮；当前 Review 给当轮有效 findings，不把历史总量当未解决数量。
